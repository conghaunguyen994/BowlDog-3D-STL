> **Mẹo trên GitHub:** Bạn có thể nhấn trực tiếp vào từng file `.stl` bên dưới ngay trên giao diện web của GitHub để **xoay và xem mô hình 3D trực tiếp (3D Viewer)** hoặc nhấn nút **Download Raw File** để tải về máy đem đi in.
